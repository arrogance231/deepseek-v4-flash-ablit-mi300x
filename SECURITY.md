# Security policy

Do not report secrets, access tokens, private IPs, or unredacted service
credentials in public issues. Rotate any credential that was accidentally
exposed and report the incident privately to the repository owner.

Runtime bugs, crashes, incorrect outputs, and suspected kernel corruption can
be reported publicly when the report contains no sensitive data. Include the
model revision, vLLM image digest, ROCm version, command-line flags, and a
minimal reproduction where possible.
